### 2주차 - 실습 환경 구축과 버전 관리 기초

## 리눅스 기본 명령어
- pwd : 현재 작업 디렉터리 확인
- ls : 파일 및 디렉터리 목록 확인
- cd : 디렉터리 이동
- mkdir : 디렉터리 생성
- touch : 빈 파일 생성
- cat : 파일 내용 확인

## git 버전 관리
- repository : 프로젝트 저장소
- commit : 변경 사항 기록
- branch : 독립적인 작업 공간
- push : 로컬 변경 사항을 원격 저장소에 업로드

## 주요 명령어

# 폴더 생성 및 이동
mkdir -p ~/devops/week02
cd ~/devops/week02

# git 상태 확인
git status

# 변경 파일 추가
git add .

# 변경 내용 저장
git commit -m "week02: 실습 정리"

# github에업로드
git push
