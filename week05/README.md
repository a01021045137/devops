## 주요 학습 내용

#docker란?
애플리케이션과 실행 환경을 컨테이너로 묶어 실행할 수 있도록 지원하는 플랫폼

# 주요 Docker 명령어
- docker run : 컨테이너 생성 및 실행
- docker ps : 실행 중인 컨테이너 확인
- docker images : 이미지 목록 확인
- docker logs : 컨테이너 로그 확인
- docker exec : 실행 중인 컨테이너 내부 명령 실행
- docker stop : 컨테이너 중지
- docker rm : 컨테이너 삭제
